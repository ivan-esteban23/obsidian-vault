# Using Media DB

Use the command palette and choose **Media DB: Create entry (Book)** or **Media DB: Create entry (Music Release)**. Select OpenLibraryAPI for books or MusicBrainz API for music, search by title, and choose the matching author or artist and edition or release.

New book and music notes are saved in the Books and Music folders here for review. Check the title, creator, date, source and cover before adapting material into the existing collection. Keep the collection's existing artwork, issue numbers, sources and editorial format. Verify any genre connections against appropriate sources; imported metadata alone does not establish them.

Covers are linked from the provider by default rather than downloaded. Existing collection notes are not changed by a search. Avoid importing duplicates or using the bulk import command on the existing collection.
