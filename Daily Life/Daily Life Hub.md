# Daily Life Hub

Use Calendar in the sidebar to open a day or create its daily note. Jot down priorities, appointments, notes, and ideas there. This calendar shows notes in this vault; it is not connected to an external calendar.

## Open tasks

Add a checkbox in any note. Use **Tasks: Create or edit task** to set a due date or recurrence; the list below gathers open tasks across the vault. Select a task to jump to its note.

```tasks
not done
sort by due
```

## A short daily review

1. Open today's note from Calendar and write your top priority.
2. Review the tasks above and choose what is realistic for today.
3. Capture ideas without editing them; revisit them during a weekly review.
4. Spend ten minutes writing and revise one passage with the checklist.
