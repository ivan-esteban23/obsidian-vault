# Brand Recommendation Matrix

Start with the missing function in the kit, then compare the appropriate products. **Strong fit** means a documented specialty; **conditional fit** requires a construction, terrain or ownership check; **outside scope** means this collection does not evaluate a suitable supplier. These are editorial selection categories, not product test results.
