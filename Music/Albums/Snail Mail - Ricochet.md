# Snail Mail — Ricochet

![[attachments/Indie 2026/04-snail-mail.jpg|320]]

**27 March 2026** · Album · Indie rock / string arrangements · Matador Records

Lindsey Jordan expands Snail Mail's third album with string arrangements and a more outward-looking set of concerns. The release notes describe dissociation in the jangling opener Tractor Beam and a preoccupation with mortality across the writing. Its eleven songs offer a substantial return after Valentine.
