# Basement — WIRED

![[attachments/Alternative 2026/06-basement.jpg|320]]

**8 May 2026** · Album · Alternative guitar rock / emo · Run For Cover Records

Basement returns to Run For Cover after an eight-year album gap. John Congleton produces, engineers and mixes a twelve-song set built around the same five-person line-up. The release notes emphasize renewed creative purpose, forceful guitars and choruses, with the title track following opener Time Waster.
